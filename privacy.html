Privacy Policy

ViceCityScreams Uploader – last updated: 20 November 2026

Which data the app uses

The app signs in to the channel owner's own Google account with OAuth and uses the YouTube Data API only to upload videos (title, description, tags, category, scheduled publish time) to the owner's own channel.

Where the data is stored

The sign-in token is stored only locally on the channel owner's computer. Nothing is sent to any server other than Google/YouTube. No analytics, no cookies, no tracking.

Sharing

No data is sold, shared or transferred to third parties.

ViceCityScreams Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google security settings page).

Data deletion

The only stored data is the local sign-in token on the channel owner's computer. It is deleted by deleting the token file or by revoking access as described above; after revocation the token can no longer be used. No other copies exist, and no data from YouTube API Services is stored by the tool.

YouTube

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
